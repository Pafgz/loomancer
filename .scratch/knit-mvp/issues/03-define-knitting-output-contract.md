# Define the Chart Output Contract

Type: grilling
Status: resolved
Blocked by: 02

## Question

Which chart constraints and output artifacts must the MVP support so an image-derived pattern is usable rather than merely visual?

## Answer

The output is a rectangular Colorwork Chart whose cells each represent one stitch. It must show:

- total stitch width and row height;
- visible grid lines with row and column coordinates;
- a distinct symbol as well as a color for every chart color, so the pattern remains usable when printed or viewed with color-vision differences;
- a side color key listing each symbol, display color, chosen yarn label, and stitch count;
- the current crop and chart dimensions before export.

The Knitter can export a printable PDF or save a high-resolution chart image to their device/photo library. Both exports include the chart and color key. The MVP does not generate garment construction, sizing, gauge, or yarn-quantity instructions.
