# Audit Dreamknit's Public Product

Type: research
Status: resolved
Blocked by: none

## Question

Which publicly observable Dreamknit capabilities and user journeys are relevant to the core knitting-pattern creation loop, and which should be treated as later parity work?

## Answer

Website crawling was stopped at the owner's request. The authoritative later-parity backlog is the owner-provided list in [dreamknit-feature-list.md](../../../docs/research/dreamknit-feature-list.md).

For the focused MVP, Dreamknit features are inspiration only. Photo-pixelization into an editable Colorwork Chart with Yarn Inventory matching remains Knit-Pro's differentiator.

Deferred from the owner list unless a future destination explicitly includes them:

- design extras such as AI pattern generation, 3D colorway visualization, stitch libraries, custom sizing, and PDF/image import beyond the MVP chart loop;
- project-management tools such as row counters, dashboards, time estimates, and interactive checklists;
- inventory extras such as barcode scanning, needle/notion tracking, shopping alerts, and gauge-based substitution;
- community/marketplace features;
- advanced accessibility modes beyond the Studio defaults already required by the MVP.

None of those expand the first release beyond the local image-to-Colorwork-Chart loop.
