# Define the Target Knitter and MVP Journey

Type: grilling
Status: resolved
Blocked by: none

## Question

Who is the first release for, what knitting knowledge can it assume, and what single end-to-end outcome must that person achieve?

## Answer

The MVP is for a **confident beginner**: someone who knows basic knitting and can follow a colorwork chart, but should not need image-editing expertise.

Their end-to-end outcome is an editable, image-derived **Colorwork Chart** with a clear color key. Garment construction, sizing, gauge, and fit are not part of this MVP.

The core journey is:

1. Start a Pattern Project.
2. Upload and crop an image.
3. Choose the stitch-grid resolution and color count.
4. Generate and edit the Colorwork Chart.
5. Match or replace chart colors using yarn already owned.
6. Export the chart and color key.
