# Set MVP Product Boundaries

Type: grilling
Status: resolved
Blocked by: 02, 06

## Question

Which account, persistence, export, pricing, sharing, catalog, and community capabilities are required for the first useful release, and which are explicitly deferred?

## Answer

The MVP is a responsive web app that can be installed as a PWA and used on desktop, tablet, or phone.

Required:

- create a Pattern Project without an account;
- select a source image from the device or photo library;
- save Pattern Project drafts and Yarn Inventory locally on that device;
- reopen, rename, duplicate, and delete local drafts;
- export PDF and high-resolution image outputs;
- use the operating system's share/save capability when available, with file download as fallback;
- explain clearly that local data is not synchronized or backed up.

Deferred:

- accounts, cloud sync, collaboration, and sharing links;
- pricing, subscriptions, and payments;
- public pattern catalogs, marketplaces, likes, comments, and community features;
- manufacturer yarn catalogs and commerce integrations;
- native mobile applications;
- analytics that upload source images or chart contents.

Dreamknit parity does not expand this boundary: only capabilities required for the focused image-to-chart loop enter the MVP.
